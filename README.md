# 生日祝福网页 🎂

一个带有蛋糕动画、烟花特效和照片墙的生日祝福网页。

## 功能

- **蛋糕动画** — 三层蛋糕 + 5根蜡烛，火焰摇曳、奶油裱花
- **星空背景** — 动态闪烁星星，缓慢漂移
- **烟花粒子** — 点击任意位置释放烟花
- **漂浮气球** — 彩色气球从底部升起
- **祝福语输入** — 输入名字或祝福语，全屏大字展示 + 撒花
- **照片墙** — 点击祝福后切换，图片不规则排列、缓动浮动、点击放大

## 如何替换图片

1. 将你的照片放入 `img/` 文件夹
2. 按数字顺序命名：`1.jpg`、`2.jpg`、`3.jpg` …（支持 jpg / png / jpeg / webp）
3. 刷新页面，照片墙会自动显示你的图片

> 未放入图片时，照片墙会显示灰色占位卡片。

## 文件结构

```
birthday.html   # 主页面（单文件，直接双击打开）
img/            # 图片目录（需自行创建并放入照片）
  ├── 1.jpg
  ├── 2.jpg
  ├── 3.png
  └── ...
README.md
```

## 本地使用

直接双击 `birthday.html` 在浏览器中打开即可。
